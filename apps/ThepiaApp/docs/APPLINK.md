# iOS Applinks

The individual apps are hosted on flows.thepia.net. There is the demo app and customer specific ones that can be hosted on a subdomain of thepi.net or the customers domain. These domains can host the admin interface to be used on larger screens in a browser. Mobile devices can open the apps using applinks under the app.thepia.net domain.

The basic app logic is managed under app.thepia.net. You can provide an app link to a customer specific app by using the following format:

https://app.thepia.net/<domain>

Domain might be
- talki.dev
- flows.nets.eu
- db.thepia.net
